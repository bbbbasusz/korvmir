### 한글의 세계 문자 변환기

**КорВМир**는 한글 텍스트를 음운 단위로 분석하여 다양한 세계의 문자 체계에 맞는 표기로 변환하는 웹 기반 변환기입니다. 한국어의 발음과 음운 규칙을 바탕으로 변환하며, 문자 체계별 대응 규칙과 세부 음운 규칙을 선택하여 결과를 확인할 수 있습니다.

## 주요 기능

* **한글 → 세계 문자 변환**
  한글 입력을 음운 단위로 분석하고 다양한 문자 체계에 맞게 변환합니다.
* **다양한 문자 체계 지원**
  라틴·키릴 문자, 일본어 가나, 중국어 관련 표기, 조지아·히브리·아르메니아 문자 등 다양한 표기를 지원합니다.
* **음운 기반 변환**
  단순 문자 치환이 아닌 중간 음운 표현을 거쳐 선택한 문자 체계의 규칙에 따라 변환합니다.
* **세부 음운 규칙 설정**
  지명 인식, 음절 구분, 형태소 경계, ㄴ 첨가, 사이시옷, 중세국어, 반모음화 등의 규칙을 선택적으로 적용할 수 있습니다.
* **표지(Marker) 기능**
  `|`와 `'`를 사용하여 단어·음운 경계를 지정하고 변환에 반영할 수 있습니다.
* **중간 변환 결과 확인**
  최종 결과뿐 아니라 변환 과정의 중간 형태도 확인할 수 있습니다.
* **대응표 제공**
  선택한 문자 체계의 한글 음운 대응 관계를 표로 확인할 수 있습니다.
* **한국어 지명 지도**
  인터랙티브 지도를 통해 지역을 탐색하고 지명을 선택한 문자 체계로 변환할 수 있습니다.
* **다국어 UI**
  한국어, 러시아어, 영어 인터페이스를 지원합니다.
* **복사 기능**
  변환 결과를 클립보드에 바로 복사할 수 있습니다.

## 사용 방법

1. 변환할 **문자 체계**를 선택합니다.
2. 입력창에 **한글 또는 로마자 표기**를 입력합니다.
3. 필요한 경우 **세부 음운 규칙과 Marker**를 설정합니다.
4. 변환된 **최종 결과와 중간 변환 형태**를 확인합니다.
5. 필요한 경우 **대응표**를 통해 변환 규칙을 확인합니다.
6. **복사 버튼**으로 결과를 가져갑니다.
7. 지명은 **지도 기능**에서 지역을 선택하여 변환할 수 있습니다.
