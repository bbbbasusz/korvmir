# КорВМир

### 한글의 세계 문자 변환기

**КорВМир**는 한글 텍스트를 음운 단위로 분석하여 다양한 세계 문자 체계에 맞는 표기로 변환하는 웹 기반 변환기입니다. 문자 체계별 대응 규칙과 한국어의 세부 음운 규칙을 적용하여 변환 결과와 중간 변환 과정을 확인할 수 있습니다.

> 🔗 **[변환기 바로가기](https://bbbbasusz.github.io/korvmir/)**

## 주요 기능

* **한글 → 세계 문자 변환** — 다양한 문자 체계에 맞게 한글을 변환합니다.
* **다양한 문자 체계 지원** — 라틴·키릴 문자, 일본어 가나, 중국어 관련 표기, 조지아·히브리·아르메니아 문자 등을 지원합니다.
* **음운 기반 변환** — 중간 음운 표현을 거쳐 문자 체계별 규칙에 따라 변환합니다.
* **세부 음운 규칙** — 지명 인식, 음절 구분, 형태소 경계, ㄴ 첨가, 사이시옷, 중세국어, 반모음화 등의 규칙을 선택할 수 있습니다.
* **Marker 기능** — `|`, `'`를 사용하여 단어 및 음운 경계를 지정할 수 있습니다.
* **중간 변환 확인** — 최종 결과와 함께 변환 과정의 중간 형태를 확인할 수 있습니다.
* **대응표 제공** — 선택한 문자 체계의 한글 음운 대응 관계를 확인할 수 있습니다.
* **한국어 지명 지도** — 지도에서 지역을 탐색하고 지명을 선택한 문자 체계로 변환할 수 있습니다.
* **다국어 UI** — 한국어, 러시아어, 영어 인터페이스를 지원합니다.
* **복사 기능** — 변환 결과를 클립보드에 바로 복사할 수 있습니다.

## 사용 방법

1. 변환할 **문자 체계**를 선택합니다.
2. 입력창에 **한글 또는 로마자 표기**를 입력합니다.
3. 필요한 경우 **세부 음운 규칙과 Marker**를 설정합니다.
4. **변환 결과와 중간 변환 형태**를 확인합니다.
5. **대응표**에서 문자 체계별 대응 규칙을 확인합니다.
6. **복사** 버튼으로 결과를 사용할 수 있습니다.
7. 지명은 **지도 기능**에서 지역을 선택하여 변환할 수 있습니다.

# КорВМир

### Конвертер корейского текста в мировые письменности

**КорВМир** — веб-конвертер, который анализирует корейский текст на фонемном уровне и преобразует его в различные мировые системы письменности. Пользователь может применять правила соответствия для каждой письменности и дополнительные фонологические правила корейского языка, а также просматривать промежуточный результат преобразования.

> 🔗 **[Открыть конвертер](https://bbbbasusz.github.io/korvmir/)**

## Основные функции

* **Преобразование корейского текста** — преобразование корейского текста в различные системы письменности.
* **Поддержка различных письменностей** — латиница, кириллица, японская кана, варианты записи, связанные с китайским языком, грузинское, еврейское, армянское письмо и другие.
* **Фонологическое преобразование** — преобразование выполняется через промежуточное фонологическое представление с учётом правил выбранной письменности.
* **Дополнительные правила** — распознавание географических названий, разделение слогов, границы морфем, вставка ㄴ, сейсисот, среднекорейский язык, полугласные и другие правила.
* **Маркеры** — символы `|` и `'` позволяют указывать границы слов и фонологических последовательностей.
* **Промежуточная форма** — можно просматривать не только конечный результат, но и промежуточную форму преобразования.
* **Таблица соответствий** — показывает соответствия между корейскими звуками и выбранной письменностью.
* **Карта корейских географических названий** — позволяет выбирать регионы на карте и преобразовывать их названия.
* **Многоязычный интерфейс** — корейский, русский и английский языки.
* **Копирование результата** — результат можно быстро скопировать в буфер обмена.

## Использование

1. Выберите нужную **систему письменности**.
2. Введите **корейский текст или романизацию**.
3. При необходимости настройте **фонологические правила и маркеры**.
4. Проверьте **конечный и промежуточный результаты**.
5. Используйте **таблицу соответствий** для просмотра правил преобразования.
6. Нажмите **«Копировать»**, чтобы скопировать результат.
7. Для географических названий используйте **интерактивную карту**.

# КорВМир

### Korean-to-World Writing System Converter

**КорВМир** is a web-based converter that analyzes Korean text at the phonological level and converts it into various writing systems around the world. It applies writing-system-specific correspondence rules and optional Korean phonological rules while allowing users to inspect both the final and intermediate results.

> 🔗 **[Open Converter](https://bbbbasusz.github.io/korvmir/)**

## Key Features

* **Korean → World Writing Systems** — converts Korean text into various writing systems.
* **Multiple Writing Systems** — supports Latin and Cyrillic scripts, Japanese kana, Chinese-related notation, Georgian, Hebrew, Armenian, and more.
* **Phonological Conversion** — converts Korean through an intermediate phonological representation according to the rules of the selected writing system.
* **Advanced Phonological Rules** — includes place-name recognition, syllable division, morpheme boundaries, ㄴ insertion, 사이시옷, Middle Korean, semivowel conversion, and other rules.
* **Marker Support** — `|` and `'` can be used to specify word and phonological boundaries.
* **Intermediate Results** — allows users to inspect the intermediate form as well as the final result.
* **Correspondence Table** — provides a reference for Korean sound-to-script correspondences.
* **Korean Place-Name Map** — allows users to explore regions on an interactive map and convert place names.
* **Multilingual Interface** — supports Korean, Russian, and English.
* **Copy Function** — quickly copies the converted result to the clipboard.

## How to Use

1. Select the desired **writing system**.
2. Enter **Korean text or romanization**.
3. Configure **phonological rules and markers** if needed.
4. Check the **final and intermediate results**.
5. Use the **correspondence table** to review the conversion rules.
6. Click **Copy** to copy the result.
7. Use the **interactive map** to convert Korean place names.
